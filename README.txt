ANEESHA — FINAL BIRTHDAY PAGE

1. Open index.html through a local server/browser.
2. The date countdown targets 21 September 2026 at 00:00 IST.
3. After the 3-2-1 countdown, the original birthday particle sequence runs.
4. Background music starts when the 3-2-1 countdown completes.
5. The supplied message video is included as assets/message.mp4.
6. When the message video plays, the background music pauses.
7. When the message video ends, the music resumes and the reference heart animation begins.
8. The heart ending recreates the Python code visible in the supplied reference video in JavaScript Canvas:
   - same parametric heart equation
   - 10,000 soft random strokes
   - 3,500 brighter outline strokes
   - same random scale/angle/length ranges
9. assets/music.mp3 is an original soft ambient instrumental made for this page. Replace it with your preferred music file if desired, keeping the filename music.mp3.
10. TEST_MODE is OFF for the final build.

Important browser note:
Modern mobile browsers can block audible autoplay. The page primes the music muted and then unmutes it at countdown completion. If a browser still blocks it, the first tap/keypress on the page enables playback.
